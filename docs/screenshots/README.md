# Screenshots

Captures d'écran pour illustrer le projet dans le README principal.

## Fichiers attendus

| Nom | Route | Résolution recommandée |
|---|---|---|
| `home.jpg` | `/` (Espace Voyageur) | 1440 × 900 |
| `dashboard.jpg` | `/analyste` (Vue générale) | 1440 × 900 |
| `justification.jpg` | `/analyste/justification` | 1440 × 900 |

## Comment les capturer

1. Lancer l'app en local : `cd web && npm run dev`
2. Ouvrir Chrome à `http://localhost:5173`
3. `F12` → mode responsive → 1440 × 900
4. Attendre que les graphes soient chargés
5. Screenshot (Cmd+Shift+4 sur Mac, Snipping Tool sur Windows)
6. Enregistrer en JPG (qualité 85 %) dans ce dossier

Puis les images apparaîtront automatiquement dans le README principal.
